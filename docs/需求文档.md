# 打卡精灵 — 儿童语音打卡工具 需求文档

## 1. 项目概述

一款给小朋友使用的语音打卡工具，以 PWA 形式部署在 iPad 桌面，通过"打卡精灵"角色化语音交互完成每日任务打卡与积分管理。

### 1.1 目标用户

- **主要用户**: 3~12 岁儿童（通过语音交互使用）
- **管理员**: 家长（通过管理界面配置任务和查看统计）

### 1.2 使用场景

小朋友每天早上打开 iPad 上的"打卡精灵"，用语音询问今日任务，完成任务后用语音告知"打卡精灵"进行打卡，并获得积分奖励。

---

## 2. 功能需求

### 2.1 任务管理（家长侧）

| 功能 | 说明 |
|------|------|
| 创建任务 | 家长添加每日任务，如：背古诗、刷牙、整理书包等 |
| 任务属性 | 任务名称、积分值（每个任务可单独设置积分）、适用日期（每天/工作日/周末） |
| 编辑/删除任务 | 对已有任务进行修改或删除 |
| 任务排序 | 支持通过 sortOrder 控制显示顺序 |

### 2.2 语音交互（儿童侧）

| 功能 | 说明 |
|------|------|
| 唤醒对话 | 点击麦克风按钮开始语音交互 |
| 查询任务 | 小朋友说："打卡精灵，今天有什么任务" → 语音播报当日所有待完成任务 |
| 完成任务 | 小朋友说："XXX 任务已完成" → 自动匹配任务并标记完成 |
| 查询进度 | 小朋友说："我还剩几个任务" → 语音播报剩余未完成任务 |
| 查询积分 | 小朋友说："我有多少积分" → 语音播报当前总积分 |
| 语音合成 | 打卡精灵用语音回复小朋友，语速放缓、语气亲切 |

### 2.3 积分系统

| 功能 | 说明 |
|------|------|
| 积分奖励 | 每完成一个任务获得对应积分 |
| 积分展示 | 主界面醒目展示当前总积分和今日获得积分 |
| 积分记录 | 查看历史积分获取记录（时间、任务、积分值） |

### 2.4 数据管理

| 功能 | 说明 |
|------|------|
| 本地存储 | 所有数据存储在浏览器本地 IndexedDB |
| 数据导出 | 支持查看历史打卡记录 |

---

## 3. 非功能需求

### 3.1 技术栈

- 纯前端，Vue 3 + Vite + TypeScript
- Web Speech API 实现语音识别和语音合成
- PWA 可添加到 iPad 桌面全屏运行
- IndexedDB 存储数据

### 3.2 兼容性

- 目标平台: iPad Safari（iOS 15+）
- 语音识别: 中文普通话（zh-CN）

### 3.3 界面要求

- 色彩明亮、卡通风格、大按钮
- 字体大而清晰
- 动画反馈（完成任务时的庆祝效果）

## 5. 语音交互流程

### 5.1 查询任务

```
小朋友: "打卡精灵，今天有什么任务"
打卡精灵: "你今天有 5 个任务：背古诗、刷牙、整理书包、跳绳100个、喝水。加油哦！"
```

### 5.2 完成任务

```
小朋友: "背古诗已完成"
打卡精灵: "太棒了！背古诗完成，获得 5 积分！你还有 4 个任务没完成..."
```

### 5.3 查询进度

```
小朋友: "我还剩几个任务"
打卡精灵: "你今天还有 3 个任务没完成：整理书包、跳绳100个、喝水。"
```

### 5.4 查询积分

```
小朋友: "我有多少积分"
打卡精灵: "你现在一共有 120 积分，今天获得了 15 积分。"
```

## 6. 部署方式

采用 Vercel 部署，所有数据存储在 iPad 本地 IndexedDB 中，不上传任何服务器。
