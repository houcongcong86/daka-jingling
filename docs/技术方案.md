# 打卡精灵 — 技术方案

## 1. 技术选型

### 1.1 总体架构

```
┌─────────────────────────────────────────┐
│            PWA Shell                     │
│  (manifest.json + service worker)        │
├─────────────────────────────────────────┤
│          Vue 3 + Vite (SPA)             │
├──────────────┬──────────────────────────┤
│  儿童模式     │       家长管理模式         │
│  (语音交互)   │       (任务配置)          │
├──────────────┴──────────────────────────┤
│        状态管理: Pinia                    │
│        持久化: IndexedDB (idb)           │
│        语音: Web Speech API              │
│        样式: UnoCSS                      │
└─────────────────────────────────────────┘
```

### 1.2 核心依赖

| 技术 | 选型 | 原因 |
|------|------|------|
| 框架 | Vue 3 + Composition API | 轻量、响应式 |
| 构建 | Vite | 快速 HMR、PWA 插件 |
| 状态管理 | Pinia | 简洁 |
| 路由 | vue-router | 双模式切换 |
| 存储 | idb (IndexedDB) | 结构化存储 |
| 样式 | UnoCSS | 按需生成 |
| PWA | vite-plugin-pwa | 自动生成 SW |
| 语音 | Web Speech API | 浏览器原生、免费 |

## 3. 数据流设计

### 3.1 整体数据流

```
IndexedDB (持久层) ←→ Pinia Store (状态层) ←→ Vue 视图 + 语音引擎
```

### 3.2 语音交互数据流

```
小朋友说话 → SpeechRecognition → useVoiceCommands 解析
  → 匹配命令 → 操作 Store → 生成回复文本 → SpeechSynthesis → 小朋友听到
```

### 3.3 命令匹配策略

采用关键词模糊匹配：
- "背古诗已完成" → 匹配任务名"背古诗" + 关键词"已完成"
- 支持变体：做完了、完成了、搞定、打卡

## 5. 语音模块

### 5.1 useSpeechRecognition

- 封装 Web Speech API
- lang: zh-CN, continuous: true, interimResults: true

### 5.2 useSpeechSynthesis

- rate: 0.9（适合儿童）, pitch: 1.2

### 5.3 useVoiceCommands

- parse(text) → VoiceCommand
- execute(command) → reply text

## 10. 部署方案 (GitHub Pages)

### 10.1 总体原则

所有打卡数据存储在 iPad 本地 IndexedDB 中，部署平台**只托管前端静态页面文件**，不接触任何用户数据。

### 10.2 部署方式对比

| 特性 | Vercel | Surge.sh | Cloudflare Pages | Coding Pages | Gitee Pages | **GitHub Pages** |
|------|--------|----------|-----------------|-------------|-------------|-----------------|
| **费用** | 免费 | 免费 | 免费 | 免费（6个月流量包） | 免费 | **免费** |
| **HTTPS** | ✅ 自动 | ✅ 自动 | ✅ 自动 | ✅ 自动 | ✅ 自动 | **✅ 自动** |
| **实名认证** | ❌ 不需要 | ❌ 不需要 | ❌ 不需要 | ✅ 需要 | ✅ 需要 | **❌ 不需要** |
| **国内访问** | ❌ 被屏蔽 | ❌ 不稳定 | ⚠️ 免费版不稳定 | ✅ 国内快 | ❌ 已关闭 | **⚠️ 有时快有时慢** |
| **部署方式** | 一行命令 | 一行命令 | Wrangler CLI | Git 推送 + CI/CD | Git 推送 | **Git 推送 + GitHub Actions** |

### 10.3 当前选用方案：GitHub Pages

| 项目 | 说明 |
|------|------|
| 访问地址 | `https://houcongcong86.github.io/daka-jingling/` |
| 部署方式 | GitHub Actions CI/CD，推送到 main 分支自动部署 |
| 仓库 | `https://github.com/houcongcong86/daka-jingling` |
| 构建产物 | `dist/` 目录（已提交到仓库） |

**优点**：
- ✅ 完全免费，无需实名认证
- ✅ 自动 HTTPS
- ✅ GitHub Actions 自动化部署

**Vite 配置要点**：
- `base: '/daka-jingling/'` — 子目录部署
- 路由使用 `createWebHashHistory()` — 避免 SPA 404

### 10.4 部署步骤

```bash
# 1. 本地构建（验证通过）
npm run build

# 2. 提交代码
git add dist/
git commit -m "构建更新"
git push origin main

# 3. GitHub Actions 自动部署（约 1 分钟）
# 访问 https://houcongcong86.github.io/daka-jingling/
```

### 10.5 iPad 安装

1. Safari 打开 `https://houcongcong86.github.io/daka-jingling/`
2. 分享 → 添加到主屏幕
3. 全屏运行

### 10.6 安全说明

- 所有数据存储在 iPad 本地 IndexedDB
- GitHub Pages 仅托管静态文件
- 家长密码明文存储（安全边界为 iPad 锁屏密码）
