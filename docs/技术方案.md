# 打卡精灵 — 技术方案

## 1. 技术选型

### 1.1 总体架构

```
┌─────────────────────────────────────────┐
│            PWA Shell                     │
│  (manifest.json + service worker)        │
├─────────────────────────────────────────┤
│          Vue 3 + Vite (SPA)             │
├──────────────┬──────────────────────────┤
│  儿童模式     │       家长管理模式         │
│  (语音交互)   │       (任务配置)          │
├──────────────┴──────────────────────────┤
│        状态管理: Pinia                    │
│        持久化: IndexedDB (idb)           │
│        语音: Web Speech API              │
│        样式: UnoCSS                      │
└─────────────────────────────────────────┘
```

### 1.2 核心依赖

| 技术 | 选型 | 原因 |
|------|------|------|
| 框架 | Vue 3 + Composition API | 轻量、响应式 |
| 构建 | Vite | 快速 HMR、PWA 插件 |
| 状态管理 | Pinia | 简洁 |
| 路由 | vue-router | 双模式切换 |
| 存储 | idb (IndexedDB) | 结构化存储 |
| 样式 | UnoCSS | 按需生成 |
| PWA | vite-plugin-pwa | 自动生成 SW |
| 语音 | Web Speech API | 浏览器原生、免费 |

## 3. 数据流设计

### 3.1 整体数据流

```
IndexedDB (持久层) ←→ Pinia Store (状态层) ←→ Vue 视图 + 语音引擎
```

### 3.2 语音交互数据流

```
小朋友说话 → SpeechRecognition → useVoiceCommands 解析
  → 匹配命令 → 操作 Store → 生成回复文本 → SpeechSynthesis → 小朋友听到
```

### 3.3 命令匹配策略

采用关键词模糊匹配：
- "背古诗已完成" → 匹配任务名"背古诗" + 关键词"已完成"
- 支持变体：做完了、完成了、搞定、打卡

|-------------|-----|------|
| `tasks` | id (autoIncrement) | sortOrder |
| `records` | id (autoIncrement) | date, taskId, dateTaskId |
| `settings` | key (string) | — |

---

## 5. 语音模块

### 5.1 useSpeechRecognition

- 封装 Web Speech API
- lang: zh-CN, continuous: true, interimResults: true

### 5.2 useSpeechSynthesis

- rate: 0.9（适合儿童）, pitch: 1.2

### 5.3 useVoiceCommands

- parse(text) → VoiceCommand
- execute(command) → reply text

## 7. PWA 配置

- Manifest: standalone, portrait, 主题色 #FFB347
- Service Worker: 预缓存静态资源，离线可用
- iPad 适配: viewport 禁用缩放、apple-mobile-web-app-capable

---

## 8. 状态管理 (Pinia)

| Store | 职责 |
|-------|------|
| tasks | 任务 CRUD、获取今日任务 |
| records | 打卡记录、今日/总积分计算 |
| voice | 语音状态、对话历史 |
| settings | 孩子称呼、语音速度、家长密码 |

## 10. 部署方案 (Vercel)

### 部署步骤

```bash
npm run build
npx vercel dist --prod
```

### iPad 安装

1. Safari 打开部署 URL
2. 分享 → 添加到主屏幕
3. 全屏运行

### 安全说明

- 所有数据存储在 iPad 本地 IndexedDB
- Vercel 仅托管静态文件
- 家长密码明文存储（安全边界为 iPad 锁屏密码）
